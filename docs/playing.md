# 打法

給實際打這臺鍵盤的人。和弦表怎麼編、遮罩怎麼比對，見 [和弦表](chord-map-machine.md)。為什麼排成「行＋段＋拇指修飾」，見 [和弦假名](chorded-kana.md)。這裡只講手怎麼放，以及字什麼時候出去。

左右各 7 顆，都是離散開關。

| | 手指鍵 | 拇指鍵 |
| --- | --- | --- |
| 左 | `LL` `LU` `LR` `LD` | `LT0` `LT1` `LT2` |
| 右 | `RL` `RU` `RR` `RD` | `RT0` `RT1` `RT2` |

名稱第一個字母是左右手。手指鍵的第二個字母是那一側裡的方位：`L` 左、`U` 上、`R` 右、`D` 下。拇指鍵的數字是張開程度：`T0` 最合、`T2` 最開。

## 指法

- 食指、中指、無名指負責手指鍵。小指離開鍵面。
- 拇指按 `T0`／`T1`／`T2`，依手張開多少選顆，並從側面按下。
- 整隻手也可以像鋼琴一樣垂直觸鍵。側面按與垂直按，裝置都只看成「這顆按著」。
- 手指分工不固定。拇指已經在較開的鍵上時，食指可以按 `T0`。例如 `LT0+LT2`：食指按 `LT0`，拇指按 `LT2`。
- 同一組鍵換手指按，送出的字相同。韌體只看 14 顆裡哪幾顆按著（14 位元遮罩），不看是哪根手指。

## 現在字什麼時候出去

可以選兩種送出時機，由 **GPIO21** 決定。開路，或沒接這顆開關，是**全部放開再送**。接到 GND 是**這一組裡最先放開的那顆起來就送**。撥動後不用重開機。熱點頁和序列埠的 `fire` 只顯示目前是哪一種，不負責切換。試打頁的開關只影響那個瀏覽器。

兩種都是先看這一輪裡**同時按著最多顆**的那一組（一樣多顆時，留較晚的那一組），再決定何時送出一次：

- **全部放開再送。** 每一顆都放開之後才送。
- **這一組裡最先放開的那顆起來就送。** 其餘還按著的先不當下一組，要等全部放開才能開始下一輪。這一組還在按下去的途中就有鍵先起來，字會提早出去。

每顆鍵要先穩定一小段，才算按下或放開。多按到表上沒有的組合時，這一整組不送字。方向鍵和退格若表上允許連發，按住會由韌體自己重複，跟上面兩種時機分開計。

- **第一顆開始時：** 這一輪的第一顆剛按下就送。
- **全部達成時：** 等上一項判定完成才送。完成可以是全壓好，也可以是全放。

現有的「全部放開再送」接近「全放，而且全部達成才送」。它認定的是按住期間同時按下最多的那一組。「全壓好之後安靜一小段再認定」，以及「第一顆一按下就送」，都還沒有。
