# 和弦假名邏輯短說

給想理解「為什麼這樣排」的人。手怎麼放見 [打法](playing.md)；表怎麼編、怎麼比對見 [和弦表](chord-map-machine.md)。完整鍵位以 [`esp32-jis-chordboard-premapping.csv`](../esp32-jis-chordboard-premapping.csv) 為準。

普通鍵盤打日文要在子音、母音、濁點之間來回跳鍵。Kanade 把「五十音表」拆成雙手同時按的和弦（chord）：**左手選行、右手選段，大拇指修飾鍵決定有沒有濁音／半濁音／外來語**；大拇指並可單獨承擔 `ん`／`っ`／長音。程式真正送出的是 **字元組合／功能鍵／修飾鍵複合**，交給主機上的日文 IME（例如 Google 日本語入力）轉換。

---

## 設計動機：一拍一音

核心節奏是 **一個音節（一拍）≈ 一組動作**。QWERTY 上打 `a` 與打 `cha`，對同一個「一拍」來說，序列與並列按鍵的時間可差到約 **3 倍**。Kanade 用「行＋段（＋必要時的大拇指修飾鍵）」把長短壓回相近的一拍，讓打字節奏跟假名節奏對齊。

韌體側對應的是：按住期間取同時按下最多的那一組（高峰），再依送出時機送出**一次**配方。細節見 [和弦表](chord-map-machine.md)。

---

## 三件東西

左右各 7 顆離散鍵（無類比搖桿）。手指鍵的方位與拇指張開程度見 [打法](playing.md)。

| 部位 | 鍵 | 角色 | 白話 |
| --- | --- | --- | --- |
| **左手手指** | `LL` `LU` `LR` `LD`（可組合） | **行**（子音列） | 選 か／さ／た／な／は／ま／ら／わ… 那一「行」 |
| **右手手指** | `RL` `RU` `RR` `RD`，以及單母音的 `RT0` | **段**（母音／拗音） | 選 a／i／u／e／o，或 ya／yu／yo／ye |
| **大拇指** | 假名軸主要是 `LT1`／`RT1` | **修飾** | 濁音、半濁音、撥音 `ん`、促音 `っ`、長音 `-`；外來語與小字也借同一套 |

人編表欄位對應：`left_fingers`／`right_fingers`／`left_thumb`／`right_thumb` → 高峰遮罩；`output` → 送出的配方。

### 右手段（母音格）

單母音與半母音不按左手時，右手 alone 就是段：

| 段 | 右手 | 例 |
| --- | --- | --- |
| あ | `RT0` | `a` |
| い | `RL` | `i` |
| う | `RU` | `u` |
| え | `RR` | `e` |
| お | `RD` | `o` |
| や | `RR+RU` | `ya` |
| ゆ | `RL+RU` | `yu` |
| よ | `RL+RD` | `yo` |
| いぇ | `RR+RD` | `ye` |

傳統子音行上，あ段常寫成 `(RT0)`：可按可不按，輸出相同。其餘段要按對應右手鍵。

### 左手行（傳統骨架）

| 行 | 左手 | 清音例 |
| --- | --- | --- |
| た | `LD` | た `ta` |
| か | `LU` | か `ka` |
| な | `LL` | な `na` |
| さ | `LR` | さ `sa` |
| ら | `LL+LD` | ら `ra` |
| ま | `LR+LD` | ま `ma` |
| は | `LR+LU` | は `ha` |
| わ（表上歸「外來語 w」） | `LL+LU` | わ `wa` |

わ行沒有再疊 `LT1` 的清音骨架；同一組左手加上拇指才變成 f／v 等外來語（見下）。

## 大拇指修飾鍵在做什麼

假名節奏裡，拇指主要扮演四種角色。鍵是 `LT1`／`RT1`；`LT0`／`RT0`／`LT2`／`RT2` 另用於方向鍵、符號與操作（見後兩節）。

### 1. 單獨：撥音／促音／長音

不選行、不選段時：

| 拇指 | 送出 | 假名 |
| --- | --- | --- |
| `LT1` | `nn` | ん |
| `RT1` | `ltu` | っ |
| `LT1`+`RT1` | `-` | ー |

### 2. `RT1`＝濁點 軸

同一組「行＋段」再加上 `RT1`，清音變濁音：

| 清音行 | ＋`RT1` |
| --- | --- |
| た | だ |
| か | が |
| さ | ざ |
| は | ば |

例：`LD`+`RL` → ち；再加 `RT1` → ぢ。

### 3. `LT1`＝半濁／小字／外來語 軸
#### 1. 半濁／小字

| 用法 | 做法 |
| --- | --- |
| 半濁音 | は行＋段＋`LT1` → ぱ行 |
| 小假名 | 單母音／やゆよ／いぇ 的右手形＋`LT1` → ぁぃぅぇぉゃゅょ；`RR+RD`+`LT1` → ゎ |

例：`LR+LU`+`RD` → ほ；再加 `LT1` → ぽ。右手 `RT0`＋`LT1` → ぁ。

#### 2. 外來語

外來語**不另開一套手指布局**。Kanade 為配合多數人的習慣，沒有把所有音節都攤成嚴格的「子音（若有）搭配母音」一張格，而是分成傳統五十音與外來語音素。較少見的音節用同一套拇指疊加：多半是 **`LT1`**，有濁音就再疊一層用 **`LT1`+`RT1`**（概念上像「外來語再疊濁」）。

| 拇指 | 典型疊加 |
| --- | --- |
| （無） | 傳統清音；わ行（`LL+LU`） |
| `RT1` | 傳統濁音 |
| `LT1` | ぱ；小字；f、kw、sh、ch、ts、ti、tu… |
| `LT1`+`RT1` | v、gw、j、di、du… |

同一左手行在不同拇指層上可以對到不同「開頭子音」。例如 `LU` 是か行；`LU`+`LT1` 是くぁ系（kw）；`LU`+`LT1`+`RT1` 是ぐぁ系（gw）。`LL+LU` 無拇指是わ；加 `LT1` 是 f；再加 `RT1` 是 v。

表上「外來語 *」區段裡，label／output 皆空的列是**預留格**，機器表會略過，不是失效錯誤。

### 實際排版怎麼落表

- **傳統清音／濁音／半濁／小字／んっー** 佔日常節奏。
- **外來語** 掛在既有左手行上，靠 `LT1` 或 `LT1`+`RT1` 換層；區段名在人編 CSV 的 `section`（如 `外來語 f`、`外來語 ti`）。
- 同一音在傳統路徑與外來語路徑可能都能打到（例如 しゃ 既在さ行拗音，也在「外來語 sh」層）。以表上列為準；比對規則見 [和弦表](chord-map-machine.md)。

## 符號：像「插播」

標點／符號不是日常假名節奏的一部分，設計上當成**插播（interrupt）**：暫時離開「行＋段＋`LT1`/`RT1`」那條軸，改用拇指較開的鍵（`T2`）或把手放到操作位。

出廠表大致分三路：

| 路 | 典型鍵型 | 例子 |
| --- | --- | --- |
| 右手插播 | 左手手指＋必按 `RT0`＋`RT2` | 「」！？『』・…… |
| 左手插播 | `LT0`＋右手手指＋`LT2` | （）※○★☆―→ 等 |
| 三指收束 | 不靠 `T1`／`T2` | 、＝`LL+LD+LR`；。＝`RL+RD+RR` |

方向鍵是另一種插播：`LT0`＋右手上下左右，可連發（`repeat=allow`）。

操作功能也離開假名軸，例如：`LT2` 退格、`RT2` 空白（變換）、雙手收滿為 Enter、`LT0`+`LT2`+`RT2` 變片假名等。完整列見人編 CSV 的「符號」「操作功能」區段。
